# Research: choose a question

Hoomy explores whether an AI companion can help people decide what deserves
attention and carry work forward under their control. Coding projects are the
current test environment. The 0.0.1 preview provides infrastructure for research;
it does not establish reliable project understanding or useful activity selection.

and what each observation leaves unresolved.

## Explore with your agent

After cloning, give your agent a question and request **code, tests, observations,
and remaining uncertainty separately**. For example:

> Trace a visible message from collection to a cited conclusion. Which code checks
> provenance, and which checks establish semantic support or current truth? Link
> the implementation, tests, and recorded limitations. Do not run inference.

> Compare the discovery and Act/Learn trials. Which outcomes were measured, which
> were user observations, and which remain design proposals? Do not treat an
> unmeasured benefit as a result.

> Help me choose one open question and prepare a bounded protocol using data I am
> authorized to process. State the baseline, evaluation rule, data recipients,
> and stop conditions before running it.

Use the [repository entry point](../../README.md) for testing and contribution
routes. Publishing code does not authorize collection, model processing, or
publication of conversation data.

## Read the records critically

- Engineering tests check a defined behavior; they do not establish user benefit.
- Operator pilots demonstrate a bounded observed path, not general performance.
- A protocol without completed observations has no result.
- An exact quotation establishes text membership, not entailment or current truth.
- Dated experiment notes describe their checkpoint. Historical paths, branches,
  and proposed steps do not override current installation or runtime contracts.
