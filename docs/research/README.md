# Hoomy Research Documentation

This directory is the living project documentation for Hoomy.

It is not the knowledge base. The knowledge base preserves source material and historical evidence. This directory guides the research project itself: what we believe, what we have decided, what remains open, what we are testing, and how we learn.

Start with:

- [Project Charter](./project-charter.md)
- [Research Ops](./ops/README.md)
- [Agentic Development Target](../architecture/agentic-development-target.md)
- [Learning Evidence and Self-hosted Training](./learning-pipeline.md)

The development target explains how Hoomy can evolve from the current private
pilot into a measured, agent-assisted software factory without moving privacy
boundaries or human decisions into an uncontrolled model loop.
