# Goal Template

Use this when starting a daily `/goal`.

```md
/goal
Today we advance:

Done when:

Constraint:

Review needed:
```

## Good Goal

```md
/goal
Today we advance: choose the first research playground
Done when: one playground, one hypothesis, one baseline, and one smallest artifact are named
Constraint: no implementation; decision only
Review needed: judge whether the playground is worth the first experiment
```

## Bad Goal

```md
/goal
Make Hoomy smarter.
```

Why bad: no artifact, no constraint, no review path.
