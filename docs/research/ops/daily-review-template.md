# Daily Review Template

Copy this into `daily/YYYY-MM-DD.md`.

```md
# Daily Review - YYYY-MM-DD

## Goal

## Done

## Evidence

## Decision Needed

## Test Or Review

## Next Proposed Goal
```

## Rules

- Keep it readable in 15 minutes.
- Link artifacts directly.
- Ask one decision question.
- Separate what changed from what was learned.
- If nothing worked, record the failure clearly.
